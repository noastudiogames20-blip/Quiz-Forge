# Quiz-Forge
Quiz Forge is a site for sharing and creating full quizzes 
Create with the help of Claude in Perplexity in HTML compiled in ZIP to be put as a website in Netlify
You can share quizzes via links available for 30 days, those who have already downloaded the quiz through this link will still have it after this date. 
The data is saved directly on the site, but if you change browsers, make sure to save all your progress.
Here is the link 🔗: https://quizforgequiz.netlify.app/ .
The website is originally in French, you need to enable your browser's automatic translation if it's not in your language
